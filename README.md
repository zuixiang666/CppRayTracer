# CppRayTracer

这是一个基于 C++ 的光线追踪（Ray Tracing）渲染器。

本项目是我在**学习计算机图形学原理**的过程中，参考经典教程 **ssloy/tinyraytracer** 一步步手动敲写并复现的成果。在这个过程中，我不仅跑通了渲染流程，还独立解决了一些跨平台的兼容性问题，并对其进行了扩展。

## 致谢

## ✨ 目前实现的核心功能

- [x] **基础渲染管线**：将三维场景渲染为自定义二进制 PPM 格式图片。
- [x] **底层数学库封装**：自定义 `Vec3` 三维向量类，重载了基础运算符（加、减、点乘、标量乘、下标访问），并实现了向量归一化。
- [x] **碰撞检测**：实现射线与球体（Sphere）的相交检测，支持多球体的深度遮挡排序（Occlusion）。
- [x] **Phong 光照模型**：引入点光源与材质系统，实现了基于法线点乘的漫反射（Diffuse）与高光（Specular）计算。
- [x] **阴影（Shadows）**：通过向光源发射阴影射线（Shadow Rays）检测遮挡，并通过“阴影偏移（Shadow Offset）”技术完美解决自遮挡引起的“阴影痤疮”伪影。
- [x] **镜面反射（Reflection）**：实现递归光线追踪，支持完美的镜面反射材质，并设置了递归深度（Depth）防止栈溢出。
- [x] **抗锯齿（Anti-Aliasing）**：实现基于超采样（SSAA）的 4x4 多光线采样，并引入随机偏移量，极大平滑了物体边缘的锯齿。
- [x] **色调映射（Tone Mapping）**：在写文件前进行颜色截断与防过曝处理，保证高光区域的细节。
- [x] **光线折射（Refraction）**：基于斯涅尔定律实现透明材质的折射计算，扩展了Vec4材质系统，成功渲染出逼真的玻璃质感
- [x] **多几何体混合渲染**：打破单一球体限制，查阅图形学原理，成功引入 **AABB（轴对齐包围盒）光线求交算法**，支持正方体（多面体）与球体的混合渲染。
- [x] **几何体法线推导**：针对 AABB 包围盒特性，通过比较交点与包围盒中心的相对距离（`fabs(d.x)` 等），自行推导并编码了面法线计算逻辑。
- [x] **材质与光影调优**：通过深度调节 `Vec4f` 材质参数，成功渲染出带有金属质感与清晰阴影的立体方块。

## 学习心得 / 踩坑记录
在复现本项目的过程中，我踩过以下几个坑，在此记录：
1. **文件流模式**：在 Windows 下使用 `std::ofstream` 写入二进制图片时，必须加上 `std::ios::binary`，否则换行符会被强制转换，导致图片乱码。
2. **射线方向**：计算光线方向向量后，必须进行**归一化（Normalize）**，否则会导致求交公式计算出错，屏幕全红。
3. **宽高比（Aspect Ratio）**：在将屏幕坐标映射到三维空间时，必须考虑屏幕的宽高比，否则渲染出的球体会变成椭圆。
4. **运算符重载**：在实现光照模型时，由于需要计算 `颜色向量 * 光照强度`，原有的 `Vec3f` 类只支持点乘（返回 float），不支持向量乘标量。通过阅读编译器报错，我手动在 `geometry.h` 中重载了 `operator* (const float &scalar)`，使其返回一个新的三维向量，成功解决了 `const Vec3f * float` 的编译错误。
5. **阴影伪影（Shadow Acne）**：通过判断法线与光源方向，将阴影射线起点沿法线方向偏移 `1e-3`，完美消除表面的黑色噪点。
6. **四维向量扩展**：在实现折射时，原材质的三个比例（漫反射、高光、反射）不够用了，需要增加折射率。通过新增Vec4类并扩展运算符重载，完美解决了材质属性的存储问题

## 🧗 进阶探索：OBB 包围盒与旋转投影的几何视觉

在实现了基础的 AABB（轴对齐包围盒）正方体后，我尝试进一步挑战 OBB（有向包围盒），让几何体在空间中产生旋转角，带来更丰富的立体感。

1. **旋转矩阵的引入**：
   为了实现 45 度倾斜，我没有直接修改顶点坐标，而是通过 `sin`/`cos` 构建旋转矩阵，对入射光线进行了反向坐标变换，并对求交后的法线进行了坐标系映射转换。
2. **奇妙的视觉投影现象**：
   在 45 度的特定视角下，正方体的 2D 投影呈现出了类似**“青绿色透明六边形柱体”**的奇妙几何形态。由于材质赋予了较高的反射率与高光参数，它奇妙地融合了背景的天空蓝与前景的玻璃球倒影。
3. **复盘思考**：
   这个视觉效果让我直观感受到了三维几何在透视投影下的魅力。虽然 OBB 算法在复杂的材质反射下会让法线计算变得非常敏感，但这无疑是一次极好的底层数学训练。

## 🧗 进阶探索与 Debug 记录：从 OBB 翻车到 AABB 视角优化
1. **初始翻车（OBB 的陷阱）**：
   为了让正方体拥有倾斜的立体感，我尝试引入旋转矩阵（`sin`/`cos`）对光线进行反向旋转，试图实现有向包围盒（OBB）。但由于旋转后**法线没有正确转换回世界坐标系**，导致光照计算崩溃，正方体变成了一个布满噪点的“半透明青绿色六棱柱”。
2. **硬核排错与回归**：
   通过复盘底层数学逻辑，我意识到在没有加速结构的情况下，OBB 的坐标变换极易出错。我果断回滚了旋转逻辑，回归到最稳健的 AABB 求交。
3. **视角欺骗与最终呈现**：
   由于 AABB 无法直接旋转，我通过**调整相机的空间透视视角（错开 X/Y/Z 轴坐标）**，让正方体在二维屏幕上同时呈现出正面、侧面和顶面，完美营造了 3D 立体感。配合 `Vec4f` 材质的调优，最终实现了一个棱角分明、带有金属高光和真实阴影的立体方块。
